Segurança · Automação · Dados

Encontramos o problema, provamos que ele existe e escrevemos como consertar.

Trabalhamos com quatro frentes: testar a segurança de aplicações web e APIs, automatizar processos repetitivos com código próprio, montar bot de atendimento no WhatsApp e transformar dados presos em PDF, planilha ou API em informação usável.

Todo trabalho começa com escopo por escrito. Nada fora do combinado é testado — nem por curiosidade.

O que fazemos

01 — SEGURANÇA

Teste de aplicações web e APIs

Mapeamos a superfície real do alvo (endpoints, parâmetros, regras de acesso), incluindo a API interna que o site ou o app não documenta, e testamos controle de acesso, lógica de negócio e exposição de dados. Cada achado sai com prova: requisição, resposta e o impacto descrito em termos de negócio.

recon de superfície · engenharia reversa de API interna · IDOR/BOLA/BFLA · lógica de negócio · teste de funcionalidades de IA, agentes e MCP · relatório com prova de conceito

02 — AUTOMAÇÃO

Scripts, agentes e rotinas

Aquilo que alguém faz à mão toda semana vira script rodando sozinho: coleta e consolidação de dados, checagens periódicas, integrações entre sistemas que não conversam, painéis locais e fluxos com agentes de IA supervisionados.

python · linha de comando · agendamento (cron) · integração via API · painel local no navegador · agentes com verificação

03 — WHATSAPP

Bot de atendimento no zap

Bot que atende quem chama no WhatsApp: responde na hora, inclusive fora do horário, informa preço e prazo, monta o pedido ou o orçamento na própria conversa e chama um atendente humano quando o assunto sai do script. Todo atendimento fica registrado em planilha ou banco.

API oficial do WhatsApp (Cloud API) · catálogo com preços · fluxo por palavra-chave · passagem para atendente humano · registro em planilha ou sistema

04 — DADOS

Extração, consolidação e pesquisa

Extraímos o que está preso em PDF, DOCX, XLSX, e-mails ou sites, consolidamos em planilha ou banco, e devolvemos relatório com a fonte de cada número. Também mantemos monitoramentos periódicos com aviso quando algo muda.

pdf/docx/xlsx · consolidação de planilhas · relatórios com fonte citada · monitoramento de preço, site e notícias

Como trabalhamos

Escopo antes do teclado

Antes da primeira requisição, você recebe por escrito o que será testado, o que está fora e qual é o critério de parada. Sem autorização assinada, não há teste.

Prova, não opinião

Nada entra no relatório sem reprodução. Se não foi possível testar, escrevemos exatamente isso — veredito honesto vale mais que um relatório inflado.

Entrega que se usa

Achado com passos para reproduzir e correção sugerida. Código entregue no seu repositório, com instruções de operação.
